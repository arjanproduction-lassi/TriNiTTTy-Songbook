# TriNiTTTy Songbook PWA

React/Vite MVP aplikácia pre knižnicu piesní, import/edit, A4 náhľad, setlist a koncertný režim.

## Spustenie

```bash
npm install
npm run dev
```

## PWA

Po spustení cez Chrome môžeš appku nainštalovať do prehliadača alebo na Android domovskú obrazovku. Piesne, setlist a nastavenia sa ukladajú lokálne do IndexedDB.
